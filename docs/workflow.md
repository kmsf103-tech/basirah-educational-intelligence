# مخطط سير العمل – مساعد بصيرة
**Basirah – Workflow**

## 1. الهدف من سير العمل

توضيح مراحل استخدام مساعد «بصيرة» لتحليل بيانات المدارس ومؤشرات الأداء التعليمي، بدءًا من استلام البيانات وفحصها، وصولًا إلى إعداد المرئيات والتوصيات، مع الاحتفاظ بالمراجعة والاعتماد النهائي لدى المستخدم.

## 2. مراحل سير العمل

| المرحلة | الإجراء | المخرج |
|---|---|---|
| 1. استلام البيانات | تزويد المساعد بملفات البيانات وتعريفات المؤشرات والفترات الزمنية. | مجموعة بيانات للتحليل. |
| 2. فحص البيانات | التحقق من اكتمال الجداول، والقيم المفقودة، والتكرار، واتساق البيانات والعلاقات بينها. | تقرير أولي عن جودة البيانات والملاحظات. |
| 3. تحديد نطاق التحليل | تحديد المؤشرات والمستويات والفترات المطلوب تحليلها، والتحقق من ملاءمة البيانات لذلك. | نطاق تحليل واضح. |
| 4. تنفيذ التحليل | احتساب المؤشرات والنسب والمتوسطات، وإجراء المقارنات الزمنية وبين المدارس وإدارات التعليم. | نتائج كمية ومقارنات. |
| 5. الاستكشاف التحليلي | استكشاف الأنماط والفجوات والعلاقات المحتملة، واقتراح زوايا وأسئلة تحليلية إضافية. | مرئيات تحليلية وفرضيات قابلة للفحص. |
| 6. إعداد التوصيات | ربط النتائج بالفجوات، وصياغة توصيات قابلة للتنفيذ مع توضيح مبرراتها. | مسودة توصيات. |
| 7. المراجعة البشرية | مراجعة الحسابات والاستنتاجات والتوصيات والتحقق من ملاءمتها للسياق التعليمي. | ملاحظات المستخدم واعتماد أو تعديل المخرجات. |
| 8. إعداد المخرج النهائي | تنظيم النتائج والمرئيات والتوصيات في تقرير تحليلي واضح. | تقرير تحليلي جاهز للاستخدام بعد الاعتماد. |

## 3. نقطة القرار البشري

تتمثل نقطة القرار البشري الأساسية بعد انتهاء المساعد من التحليل وإعداد المرئيات والتوصيات، وقبل اعتماد التقرير النهائي.

يتولى المستخدم في هذه المرحلة:

- التحقق من صحة الحسابات ومصادر المؤشرات.
- مراجعة التفسيرات والاستنتاجات وحدودها.
- التأكد من عدم تحويل العلاقات المحتملة إلى استنتاجات سببية غير مدعومة.
- تقييم ملاءمة التوصيات للسياق التعليمي.
- اعتماد المخرجات أو طلب تعديلها واستكمال التحليل.

لا يملك المساعد صلاحية اعتماد النتائج أو إصدار قرارات إدارية أو تعليمية.

## 4. توزيع المسؤوليات

| المهمة | مساعد بصيرة | المستخدم |
|---|---|---|
| فحص البيانات | تنفيذ الفحص ورصد الملاحظات | مراجعة الملاحظات ومعالجة ما يلزم |
| تحليل المؤشرات | الحساب والمقارنة والاستكشاف | التحقق من التعريفات والنتائج |
| استخلاص المرئيات | تقديم التفسيرات والأنماط المحتملة | مناقشة الاستنتاجات وتقييمها |
| إعداد التوصيات | اقتراح توصيات مرتبطة بالنتائج | تقييم الملاءمة والاعتماد |
| التقرير النهائي | إعداد المسودة وتنظيم المخرجات | المراجعة والاعتماد النهائي |

## 5. ضوابط سير العمل

1. عدم بدء التحليل قبل فحص جودة البيانات.
2. عدم افتراض بيانات أو استكمال القيم الناقصة بأرقام غير موثقة.
3. توضيح وحدة التحليل ومستوى المقارنة.
4. التمييز بين النتائج الفعلية والفرضيات والعلاقات المحتملة.
5. توثيق حدود التحليل عند نقص البيانات أو عدم كفايتها.
6. إخضاع جميع المخرجات للمراجعة البشرية قبل استخدامها.

## 6. المبدأ الحاكم

**بصيرة يحلل ويستكشف ويناقش ويقترح، والمستخدم يتحقق ويقرر ويعتمد.**
