# قاعدة البيانات التعليمية الاصطناعية

يحتوي هذا المجلد على قاعدة البيانات التعليمية الاصطناعية المستخدمة في مشروع «بصيرة – مساعد ذكاء الأداء التعليمي».

تتكون قاعدة البيانات من ثمانية ملفات Excel مترابطة:

1. `education_directorates.xlsx` — إدارات التعليم الافتراضية (6 سجلات).
2. `schools.xlsx` — المدارس والكثافة الطلابية (30 سجلًا).
3. `subjects.xlsx` — المواد الدراسية وحد الإتقان المرجعي (6 سجلات).
4. `teachers.xlsx` — المعلمون وتوافق التخصصات (180 سجلًا).
5. `students.xlsx` — الطلاب والخصائص الاجتماعية الافتراضية (1,200 سجل).
6. `assessments.xlsx` — سجلات الاختبارات (7,200 سجل).
7. `attendance_records.xlsx` — سجلات الحضور (2,400 سجل).
8. `behavioral_incidents.xlsx` — الوقائع السلوكية الافتراضية (300 سجل).

**طبيعة البيانات:** جميع البيانات اصطناعية افتراضية بالكامل، أُنشئت لأغراض التدريب والمحاكاة، ولا تمثل أشخاصًا أو مدارس أو إدارات تعليم حقيقية، ولا تقيس الأداء التعليمي الفعلي.

**الغرض من الاستخدام:** اختبار قدرات مساعد بصيرة في فحص البيانات وتحليل المؤشرات والمقارنات واستخلاص المرئيات.

**تنبيه:** لا يجوز تفسير نتائج هذه البيانات بوصفها نتائج فعلية أو تعميمها على البيئة التعليمية الحقيقية.
